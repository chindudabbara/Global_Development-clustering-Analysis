# Global_Development-clustering-Analysis
 Executed exploratory data analysis (EDA), feature engineering, and resolved data quality issues on global development data to
prepare reliable country-level datasets for clustering.
• Analysed and compared multiple clustering algorithms including K-Means, Hierarchical, and DBSCAN to segment countries
based on socio-economic features.
• Identified K-Means as the final model with a Silhouette Score of 0.481, determined using the Elbow Method.
• Deployed the final K-Means clustering model using Streamlit to visualize country groupings and generate actionable insights
